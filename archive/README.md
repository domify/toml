# Archive

`crystal/` is toml.cr, the TOML parser for Crystal, as it was at its last
release, 0.8.1, and the commits after it up to April 2026
(crystal-community/toml.cr): its source, specs, README, shard.yml and CI
configuration, unchanged. It is kept for reference and for its history; the
iyi port at the root of this repository follows it.

To use the Crystal version, depend on
[crystal-community/toml.cr](https://github.com/crystal-community/toml.cr).
